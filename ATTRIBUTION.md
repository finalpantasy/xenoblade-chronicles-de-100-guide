# Sources and attribution

This guide combines authored route commentary with public reference material. Source URLs are retained in generated records whenever practical so individual claims can be traced.

## Primary datasets and reference projects

- [XCDE 100% Completionist Checklist](https://docs.google.com/spreadsheets/d/1glad9ZiT9Ze42KWdVH-OvNh5KAGJIBv4zlJydWdi6dc/edit?usp=sharing) — completion ledger and quest requirements used as the structured checklist baseline
- [FrontierNav](https://frontiernav.net/wiki/xenoblade-chronicles) and its [query documentation](https://docs.frontiernav.net/navigation/query) — map graph and location data; applicable FrontierNav content is used under its stated license terms
- [Xenoblade Wiki](https://xenoblade.fandom.com/wiki/Xenoblade_Chronicles:_Definitive_Edition) — enemy pages, item/drop references, area maps, character portraits, and actual game UI/art assets
- [Xenoblade Chronicles: Affinity Guide](https://gamefaqs.gamespot.com/wii/960564-xenoblade-chronicles/faqs/73533) — affinity and quest cross-checking

The detailed audit trail is in `research/`, including missables, Heart-to-Hearts, Colony 6, branch choices, quests, Unique Monsters, combat dossiers, builds, affinity, dependencies, and route/completion ordering.
